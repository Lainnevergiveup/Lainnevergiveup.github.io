# Customization Guide

## Modifying Badges

All tech stack badges use [Shields.io](https://shields.io). To replace a badge:

```markdown
![Name](https://img.shields.io/badge/LABEL-COLOR?style=flat-square&logo=LOGONAME&logoColor=white)
```

- `LABEL`: Display text
- `COLOR`: Hex color (without `#`) or named color
- `style`: `flat-square`, `for-the-badge`, `plastic`, `flat`
- `logo`: [Simple Icons](https://simpleicons.org/) slug

## Changing Theme

Stats cards use the `tokyonight` theme. Available themes:

| Theme | Style |
|-------|-------|
| `tokyonight` | Dark purple/blue |
| `radical` | Dark green/pink |
| `dracula` | Dark classic |
| `gruvbox` | Warm dark |
| `onedark` | Cool dark |
| `dark` | GitHub dark |

Update the `theme=` parameter in the stats URLs in `README.md`.

Colors used in this profile:

| Element | Color | Usage |
|---------|-------|-------|
| Accent | `#A8B8D8` | Titles, icons, streak ring |
| Text | `#8B949E` | Body text |
| Background | `#0D1117` | Card backgrounds |

## Adding Navigation Entries

Add a new entry to the Navigation Hub table in `README.md`:

```html
<td align="center" width="160">
  <a href="YOUR_URL">
    <img src="https://img.shields.io/badge/NAME-0A0A0A?style=for-the-badge&logo=LOGO&logoColor=white" alt="NAME"/>
  </a>
  <br/><sub>Short Description</sub>
</td>
```

## Adding GitHub Pages

1. Create a new repo for your page
2. Enable GitHub Pages in that repo's settings
3. Add a navigation card in the Navigation Hub section
4. Link to `https://{USERNAME}.github.io/{REPO_NAME}/`

## Adding Social Platforms

Edit the Social Platforms table in the Navigation Hub `<details>` section:

```markdown
| Platform | [your-id](https://platform.com/your-id) |
```

## Adding Academic Pages

Add entries to the Social Platforms table or create a dedicated section:

```markdown
| Google Scholar | [ID](https://scholar.google.com/citations?user=ID) |
| ORCID | [0000-0000-0000-0000](https://orcid.org/0000-0000-0000-0000) |
| ResearchGate | [Profile](https://researchgate.net/profile/YOUR-NAME) |
```

## Modifying SVG

### Typing SVG

The typing animation uses [readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg). Parameters:

- `font`: Font family
- `weight`: Font weight (400, 500, 600)
- `size`: Font size in px
- `duration`: Animation duration in ms
- `pause`: Pause between lines in ms
- `color`: Text color hex

### Snake Animation

Generated by [Platane/snk](https://github.com/Platane/snk). Configured in `.github/workflows/snake.yml`. To change the palette, modify the `outputs` section.

## Adding New Modules

To add a new section to the README:

1. Choose a position in the README structure
2. Add a `## Section Name` header
3. Use consistent formatting with existing sections
4. Maintain dark theme color compatibility

## Extending Actions

### Adding WakaTime

1. Get your WakaTime API key
2. Add it as a repository secret named `WAKATIME_API_KEY`
3. Add a step to `stats.yml` that fetches WakaTime data

### Adding Daily Quote

Add to `update.yml`:

```yaml
- name: Fetch daily quote
  run: |
    curl -s https://api.quotable.io/random | jq -r '"\(.content) — \(.author)"' > quote.txt
```
